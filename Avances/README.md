# Avances

Informes de cierre de etapa de **SelfHosted.Service.Core**.

Cada etapa del plan de desarrollo deja acá un informe autocontenido, escrito para alguien que no vio
escribir el código y se va a sentar a probarlo: qué se entregó, cómo levantarlo, qué credenciales se
generaron, qué probar paso a paso, qué debería ver y cómo está armado el proyecto.

- La regla y la plantilla obligatoria están en
  [Requerimientos-Funcionales.md §2.5](../PROMPTs/02-Ejecutar-Prompt-Integrador-Documento-Intake/INPUTs/Requerimientos-Funcionales.md).
- Para escribir un informe nuevo, copiar [`_PLANTILLA-Informe-de-Etapa.md`](_PLANTILLA-Informe-de-Etapa.md)
  con el nombre `<orden>-<etapa>.md` y completar todas las secciones.
- El informe se publica **antes** de convocar el punto de control.
- Los informes no se reescriben: sólo se actualiza su **Estado** en la sección 1 cuando el agente
  humano valida o pide correcciones.
