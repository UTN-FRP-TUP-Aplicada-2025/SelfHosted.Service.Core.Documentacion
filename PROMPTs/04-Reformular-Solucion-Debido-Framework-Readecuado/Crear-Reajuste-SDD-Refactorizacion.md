# Contexto 

  Leer `/IA/IA.SDD/README.md` es un `Framework SDD` que ha subrido cambios.

  `/DEV/SelfHosted.Service.Core` es un `repositorio destino` el cual se especifico una `el diseño de una solución` con una versión anterior de `Framework SDD`. En esa versión `Framework SDD`, no contemplaba con versión fue especificada el `el diseño de una solución`.

  Ahora, si se reejecuta el prompt orquestador o maestro sobre el  `repositorio destino` basicamente descartgaria el trabajo realizado y empezaria de vuelta. Como se han hecho avances significativos, sería conveniente armar una tarea de migración bajo alguna estrategia.

  Una estretategia sería tomar todas las especificaciones generadas actuales y trasladarlas al documento instake de la forma mas completa posible: `/DEV/SelfHosted.Service.Core/SDD/Intake/SOLUTION-INTAKE-SelfHosted-Service-Core-v1.2.md`, incluyendo todas las últimas decisiones tomadas, ajustes funcionales acordados actuales, definiciones, ejemplos, etc e incluir resumen de pendientes y decisiones: `DEV/SelfHosted.Service.Core.Documentos/PROMPTs/03-Ejecutar-Prompt-Orquestador/Historial/09.md`, luego de esto dejar listo el `repositorio destino` con su documento intake fuertemente especificado para reejecutar el prompt orquestador.

# Objetivos

  Migrar a nueva versión `Framework SDD` comptaible sin perder los avances en desiciones de diseño y ajustes funcionales acordados actuales.
